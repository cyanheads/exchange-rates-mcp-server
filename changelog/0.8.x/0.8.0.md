# 0.8.0 — 2026-11-27

## Added

- **Statutory euro conversion** uses fixed factors from each adoption date in `fx_get_rate`, `fx_convert_currency`, `fx_get_rates`, and `fx_get_timeseries` on the official configuration. Results identify the rate sources. Retired discovery includes each statutory factor and adoption date. ([#48](https://github.com/cyanheads/exchange-rates-mcp-server/issues/48))
- **Currency aliases** accept `from_currency` and `to_currency` on pair tools, `from` and `to` on point rate and conversion tools, and `symbol` on point rate and time series tools. Supply one spelling per field. ([#50](https://github.com/cyanheads/exchange-rates-mcp-server/issues/50))

## Changed

- **`fx_get_timeseries`** names the missing legs on served publication days and includes each currency's ECB coverage bounds when available. ([#49](https://github.com/cyanheads/exchange-rates-mcp-server/issues/49))
- **`fx_dataframe_query`** now returns `invalid_query` for integer `//` or `%` by zero under DuckDB 2. Wrap the expression in `TRY(...)` to retain SQL NULL.
- **`exchange-rates-guide` 1.1 → 1.2** covers statutory dates, historical units, and coverage notices.

## Fixed

- **Historical RON and TRY** results disclose restated units for observations before the respective redenominations. Unsupported ROL and TRL errors explain how to convert amounts into the accepted units. ([#47](https://github.com/cyanheads/exchange-rates-mcp-server/issues/47))
- **`fx_convert_currency`** returns `amount_out_of_range` when the converted amount would overflow.
- **`fx_dataframe_query`** renders STRUCT, MAP and LIST cells as escaped JSON in text output. ([#46](https://github.com/cyanheads/exchange-rates-mcp-server/issues/46))
- **`fx_dataframe_query` paging** uses the effective row cap in truncation notices and shows how to preserve an existing SQL `LIMIT` and `OFFSET` when paging.
