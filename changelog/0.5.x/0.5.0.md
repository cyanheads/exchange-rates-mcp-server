# 0.5.0 — 2026-10-20

## Changed

- **DataCanvas** defaults to DuckDB when `CANVAS_PROVIDER_TYPE` is unset or empty; set `none` for inline-only results. The portable Claude Desktop bundle pins `none` because it excludes native DuckDB bindings.
- **`fx_dataframe_query` breaking change:** framework adoption rejects previously supported `current_setting`, `current_schema`, `current_schemas`, `in_search_path`, `query_table`, and nonliteral `query()` calls. Use staged-table SELECTs; literal `query('SELECT …')` remains supported.
- **Currency inputs** accept `base` for `base_currency` on all four rate/conversion tools and `quote` for `quote_currency` on pair tools; sending both spellings is rejected. Advertised schemas retain canonical names. ([#24](https://github.com/cyanheads/exchange-rates-mcp-server/issues/24))
- **Conversion amounts** inherit framework representation repair: a numeric string such as `"100"` is accepted as the number `100`.
- **Bun** `1.4.2 → 1.4.3` across package-manager and Docker pins; framework development guidance and schema checks synchronized.

## Fixed

- **Caller cancellation** stops upstream fetches, response-body reads, and retry backoff across five tools and both resources, preserving the cancellation reason and independent currency-cache loads. ([#18](https://github.com/cyanheads/exchange-rates-mcp-server/issues/18))
- **Startup validation** reports invalid server configuration through the startup boundary; drop registration reads only its flag without parsing unrelated configuration. ([#20](https://github.com/cyanheads/exchange-rates-mcp-server/issues/20))
- **Canvas ownership** releases newly acquired canvases after inline-fit results, empty series, failed staging, or cancellation; supplied canvases survive and genuine spills retain usable handles. ([#25](https://github.com/cyanheads/exchange-rates-mcp-server/issues/25))
- **Expired-canvas cleanup** advises that no cleanup is needed rather than asking callers to recreate the data merely to delete it.
