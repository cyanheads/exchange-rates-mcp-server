# 0.3.1 — 2026-08-24

No container image was published for 0.3.0 — pull `0.3.1` instead.

## Fixed

- **The `Dockerfile` build stage pins to the builder's native architecture** with `FROM --platform=$BUILDPLATFORM`. The multi-arch build ran `bun run build` for `linux/amd64` under QEMU emulation, where Bun 1.4.0 aborts; TypeScript now compiles once, natively, and the `-slim` production stage stays per-target.
